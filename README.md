# SIT753 DevOps Pipeline Project

This project is a simple Node.js API used to demonstrate a full CI/CD pipeline in Jenkins, including:

- Build
- Test
- Code Quality (SonarQube)
- Security Scan
- Deploy to Staging
- Release to Production
- Monitoring

## Endpoints
- `/` – Welcome message
- `/health` – Health check
- `/add?x=1&y=2` – Returns sum
